# Forgotten Footprints

### Every abandoned machine has a story.

## About the Project

Forgotten Footprints is an educational website created for the NASA Space Apps Challenge 2026. It explores the stories of NASA equipment left behind on the Moon and Mars.

The project introduces four important missions and their equipment, explaining their purposes, scientific contributions, and what happened to them.

## Featured Equipment

### Moon
- **ALSEP (Apollo Lunar Surface Experiments Package):** Scientific instruments deployed by Apollo astronauts to study the Moon.
- **Surveyor 3:** A robotic lunar lander visited by Apollo 12 astronauts.

### Mars
- **Sojourner:** NASA's first Mars rover, part of the Mars Pathfinder mission.
- **Opportunity:** A Mars rover that explored the planet for more than 14 years.

## Features

- Homepage introducing the project.
- Separate story pages for all four machines.
- Moon and Mars filters to explore the equipment.
- Images with NASA credits and source links.
- Information about missions, discoveries, and the equipment's current status.
- Responsive design for different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the `Forgotten Footprints` folder.
3. Open `index.html` in a web browser.
4. Explore the website.

No additional installation or backend setup is required.
